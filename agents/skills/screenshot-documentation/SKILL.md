# Screenshot Documentation

Use screenshots supplied by the user or captured from the actual application using an available browser tool.
Do not substitute generated interfaces for product evidence.
If screenshots are unavailable, use a clearly labelled schematic or explain the missing evidence; do not leave unnoticed placeholders in a final manual.

- Capture the relevant screen state with enough surrounding context to locate the action.
- Remove or mask private information before embedding, without obscuring the behaviour being explained.
- Preserve aspect ratio and text legibility at final display/print size.
- Number the figure, write a specific caption and describe the task immediately beside it.
- Use sparse, consistent numbered callouts tied to instructions; avoid drawing over the target controls.
- Record the application version/environment when it affects the walkthrough.
- Check that the visible labels match the instructions and that cropped screens do not hide necessary prerequisites.

Compose with `standard-user-manual` for user manuals and the installed document/PDF skill for rendering.
