# Educational Content

Identify the learner's starting knowledge and the task they should be able to perform after the material.
Use `professional-artifact-design` for production and `content-storytelling` for the explanatory sequence.

- Teach prerequisites before dependent concepts and define unfamiliar terms where first used.
- Alternate explanation, worked example and practical application instead of providing only a feature list.
- Show inputs, method, result and interpretation in worked calculations.
- Use actual screenshots for application instructions and verified diagrams for system behaviour.
- Add practice questions or short checks when useful; provide correct answers or evaluation criteria.
- Explain common mistakes and meaningful limitations without overwhelming the main procedure.
- Distinguish factual evidence, simplified teaching models and fictional examples.
- End with a task-focused recap and a route to detailed reference material.

Validate worked answers and walkthrough steps, and inspect the final artifact at the learner's intended display or print size.
