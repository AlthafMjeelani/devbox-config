# Data Visualization

Start with the analytical question and verified data, not a preferred chart type.
Use bars for categorical comparisons, lines for ordered time, composition charts for meaningful parts of a whole and tables for precise lookup.
Prefer a small multiple or clear table to a crowded multi-axis chart.

- Verify source, period, grain, filters, units, currency, denominators and freshness.
- Recompute derived values with code or formulas; reconcile displayed totals to the underlying data.
- Preserve missing values and explain undefined ratios; do not silently substitute zero.
- Do not sum balances over time or average percentages with incompatible denominators.
- Keep comparison periods complete and comparable; distinguish snapshots from flows and forecasts from actuals.
- Use truthful scales, clear series labels, readable legends and consistent semantic colours.
- State what the visual shows and what it does not establish; correlation does not establish cause.
- Mark fictional/sample figures at the visual, not only on a distant disclaimer page.

For dashboards, test filters and trace chart ranges to their data.
For spreadsheets, recalculate formula results and check error cells.
Use editable native charts when the format skill supports them and review the final rendered chart.
